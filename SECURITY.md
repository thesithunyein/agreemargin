# Security policy

## Report a vulnerability

Use [GitHub’s private vulnerability report](https://github.com/thesithunyein/agreemargin/security/advisories/new) when available. If private reporting is unavailable, ask a maintainer for a private reporting channel before sharing details.

Include the affected URL or commit, the expected behavior, the observed behavior, and concise reproduction steps using synthetic data. Redact review and manage tokens, wallet keys, database credentials, and client information.

Please give the maintainer time to investigate before publishing details. Use your own test requests and Testnet wallets when reproducing an issue.

## Scope

The current public deployment and its source are in scope. Payment verification is limited to Sui Testnet. A review link grants client access to the request. A separate manage link grants studio access. Treat both as private and save the manage link somewhere you control.
